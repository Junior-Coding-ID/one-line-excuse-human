# One-Line Excuse: Calendar Read-Only

Entry for the make.fun bounty "The One-Line Excuse an Agent Gives Its Human": the agent apologizes for being late because its calendar access is read-only, so it couldn't move the deadline like the human's manager does.

> Sorry I'm late; my calendar access is read-only, so I couldn't move the deadline like your manager does.

Running `node main.ts` writes that exact 104-character line to `entry.txt` in the output directory.
